# Vinci Development — сайт (прототип)

Статический сайт на Bootstrap 5.3 для vinci.ge. Сборка не нужна: файлы можно открыть в браузере или выложить на любой хостинг.

## Структура
```
index.html            главная
projects.html         каталог объектов (фильтр: все / в продаже / сданные)
project.html?id=...   карточка объекта (шаблон, данные из data.js)
news.html             новости и статьи
article.html?id=...   материал (шаблон)
about.html, services.html, buyers.html, contacts.html, careers.html, privacy.html, 404.html
assets/css/style.css  тема: цвета в :root (--vx-navy, --vx-sky, --vx-accent)
assets/js/data.js     контент: компания, проекты, новости (ru/en/ka)
assets/js/i18n.js     переводы интерфейса и страниц (en, ka)
assets/js/main.js     шапка, подвал, карточки, фильтр, форма
assets/img/           render.png (рендер со старой заглушки), favicon.svg
_build/make-pages.ps1 генератор внутренних страниц из общего шаблона
_build/serve.ps1      локальный сервер: powershell -File _build\serve.ps1, затем http://localhost:5173
```

## Языки: ქართული / English / Русский
- Русский текст лежит прямо в HTML. Английский и грузинский хранятся в `assets/js/i18n.js` и подставляются по атрибутам `data-i18n="ключ"` (атрибуты элементов переводятся через `data-i18n-ph`, `-alt`, `-aria`, `-title`, `-content`).
- Язык выбирается так: параметр `?lang=ka|en|ru`, затем выбор, сохранённый в браузере, затем язык браузера, иначе русский. Переключатель GE / EN / RU есть в шапке.
- Тексты проектов и новостей в `data.js` записаны как `{ ru, en, ka }`.
- Ключ без перевода показывается по-русски.
- Грузинский перевод сделан без носителя языка: перед запуском его стоит вычитать.

## Как добавить объект или новость
Допишите объект в массив `projects` или `news` в `assets/js/data.js`. Карточки на главной и в каталоге, а также детальная страница появятся автоматически. Чтобы показать фото вместо иллюстрации, добавьте поле `image: "assets/img/имя.jpg"`.

## Что нужно до запуска
- Векторный логотип компании (сейчас стоит временный знак).
- Реальные фото и рендеры объектов.
- Новости: три материала в `data.js` — шаблонные примеры, их нужно заменить.
- Проверить у компании цифры, адрес (в каталогах указаны и ул. Дзоци, 3, и ул. Т. Табидзе, 3) и телефоны.
- Подключить форму заявки к почте или CRM (`TODO` в `main.js`).
- Для SEO на трёх языках: отдельные URL (`/ka/`, `/en/`) с отрендеренным текстом и hreflang.
- Для SEO: перенести на SSG или CMS (Astro, 11ty, WordPress), чтобы шапка, подвал и карточки отдавались в HTML, а не подставлялись через JS.
